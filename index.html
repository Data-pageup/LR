1. Project Overview

This project develops a comprehensive predictive model for student academic performance by analyzing a dataset of 80,000 student records. The primary objective is to identify factors influencing exam scores and compare the effectiveness of linear versus non-linear machine learning algorithms.

🎯 Primary Goal: Achieve high predictive accuracy while maintaining model interpretability to provide actionable insights for educational institutions.

Project Scope

  • Comprehensive exploratory data analysis (EDA)
  • Feature selection using statistical significance testing
  • Implementation of 5 regression models
  • Rigorous assumption validation
  • Model performance comparison and interpretation

6. Models Implemented

Linear Models

Multiple Linear Regression (MLR)

A baseline linear model that fits a hyperplane to the data. Highly interpretable and fast to train.

Ridge Regression

L2 regularized regression (alpha=1.0) that penalizes large coefficients to prevent overfitting and handle multicollinearity.

Lasso Regression

L1 regularized regression (alpha=0.01) that performs feature selection by shrinking insignificant coefficients to zero.

Non-Linear Models

Random Forest

Ensemble of 100 decision trees trained on random subsets, robust to outliers and captures non-linear patterns.

Support Vector Regressor (SVR)

RBF kernel SVM that maps data to higher dimensions to find optimal regression hyperplane.

8. Assumption Testing for Linear Models

Linearity ✓

Residuals vs. Fitted plots show random scatter around zero, confirming linear relationships.

Homoscedasticity ⚠️

Breusch-Pagan test: χ² = 3317.84, p < 0.001. Minor heteroscedasticity detected but does not significantly affect predictions.

Normality ⚠️

Shapiro-Wilk test: p-values ≈ 10⁻⁴⁶ to 10⁻⁴⁸. Q-Q plots show mild deviations in tails, but predictions remain reliable.

Multicollinearity ⚠️

Variance Inflation Factors (VIF):

  • motivation_level: VIF = 6.55 (moderate)
  • exam_anxiety_score: VIF = 6.37 (moderate)
  • Other variables: VIF < 3 (acceptable)

One-hot encoding causes expected correlations; Ridge/Lasso address this through regularization.

Autocorrelation ✓

Durbin-Watson Statistic ≈ 2.0 for all models, confirming no autocorrelation in residuals.

Conclusion: Linear models are robust for this dataset despite minor assumption violations. Regularized models (Ridge, Lasso) handle multicollinearity effectively.
